# ⚙️ Profile repo setup

This is the **`mukesh-03-code/mukesh-03-code`** profile repository — a
self-contained, animated cybersecurity profile README in a terminal /
matrix theme. Everything (portrait, radars, cards) is generated by the
scripts in this repo; nothing depends on flaky third-party stat sites
for the core visuals.

## Structure

```
.
├── README.md                      # the profile itself
├── assets/
│   ├── mukesh.png                 # source photo for the pixel portrait
│   ├── portrait.svg               # generated: animated duotone pixel art
│   ├── skills.json                # self-rated radar axes (edit me!)
│   ├── radar-*.svg                # generated: skill + language radars
│   ├── projects.json              # featured card order + descriptions
│   └── card-*.svg                 # generated: stats + project cards
├── scripts/
│   ├── dotify.py                  # photo -> animated pixel portrait
│   ├── radar.py                   # skills.json + live languages -> radars
│   └── cards.py                   # GitHub API -> stats & project cards
└── .github/workflows/
    ├── refresh.yml                # regenerates assets every 6h / on edit
    └── snake.yml                  # snake eats the contribution graph
```

## Regenerate assets locally

```bash
pip install Pillow
python scripts/dotify.py assets/mukesh.png -o assets/portrait.svg --cols 64 --cell 7 --animate
python scripts/radar.py     # needs network (GitHub API, unauthenticated)
python scripts/cards.py
```

## What you should edit

| File | When |
| --- | --- |
| `assets/skills.json` | Your skill ratings change — radar redraws automatically |
| `assets/projects.json` | You add/remove featured projects or change descriptions |
| `README.md` | Bio, certifications, tool badges, copy |
| `assets/mukesh.png` | You get a new photo — re-run `dotify.py` (or let the workflow do it after committing) |

## Workflows

- **Refresh profile assets** — runs every 6 hours, on every push to
  `main` that touches scripts/json, and manually via *Actions → Refresh
  profile assets → Run workflow*. Commits refreshed SVGs.
- **Generate snake** — runs every 12 hours, on push, and manually.
  **Run it once by hand** after the first upload so `output/snake.svg`
  exists for the README to embed.

Both use `GITHUB_TOKEN` — no secrets to configure.

## Publishing checklist

1. Upload this repo as `mukesh-03-code/mukesh-03-code` (public).
2. Actions tab → *Generate snake* → **Run workflow** (once).
3. Profile → *Edit profile* → website `https://mukesh-balamurugan.web.app`.
4. Pin your best repos.
